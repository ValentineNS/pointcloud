# Облако точек (PointCloud) — iPhone SE 2016

Приложение строит **облако точек из камеры** средствами ARKit. У iPhone SE 2016
нет датчика глубины (ни LiDAR, ни TrueDepth), поэтому облако разреженное — это
характерные точки, которые ARKit вычисляет для отслеживания сцены
(`ARFrame.rawFeaturePoints`) в мировых координатах.

## Что делает
- Камера + ARKit (`ARWorldTrackingConfiguration`), трекинг 6DoF.
- Накопление характерных точек между кадрами с дедупликацией по **воксельной сетке**
  (5…50 мм) и усреднением координат в вокселе.
- Отображение «сырых» точек текущего кадра (средствами ARKit) и накопленного облака.
- Встроенный **3D-просмотр** накопленного облака (кнопка «3D-вид»): вращение пальцем,
  масштаб щипком, показ габаритов в см, сброс вида. Работает без запуска камеры.
- Экспорт в три формата через системный лист «Поделиться» (Files, почта и т.п.):
  - **PLY** (binary_little_endian) — CloudCompare, MeshLab и др.;
  - **XYZ** — свободный ASCII, построчно `X Y Z` (метры), формат, который читает
    **CATIA** (`Digitized Shape Editor` → `Import` → Free ASCII);
  - **CSV** — через запятую, для Excel и скриптов.

## Ограничения
- Облако **разреженное** (сотни–тысячи точек), только на текстурных/контрастных местах.
  Гладкие однотонные поверхности дают мало точек.
- Масштаб — метры ARKit (грубая оценка; при необходимости масштабируется по
  известному отрезку в облаке).
- Плотное облако этим способом не получить — нужна фотограмметрия (SfM/MVS) на ПК.

## Сборка
Сборка без подписи на macOS-раннере GitHub Actions (как у AccelLogger):

```
Actions → Build unsigned IPA → скачать PointCloud.ipa → подписать в Sideloadly
```

Локально проект генерируется XcodeGen из `project.yml`.

## Структура
```
PointCloud/
  PointCloudApp.swift      точка входа
  ContentView.swift        интерфейс
  ARSessionController.swift сессия ARKit, накопление
  PointCloudStore.swift    воксельная дедупликация
  PLYWriter.swift          экспорт PLY
  PointCloudExporter.swift форматы PLY / XYZ / CSV
  PointCloudViewer.swift   3D-просмотр облака
  ARViewContainer.swift    ARSCNView + отрисовка облака
  ShareSheet.swift         лист «Поделиться»
  Info.plist
```
